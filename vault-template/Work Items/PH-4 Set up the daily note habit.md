## Description

Use the daily note as the front door for the day: the Plan section shows the work assigned to you, the Tasks section lists everything due today or overdue, and the Log section is for notes as the day goes.

## Acceptance criteria

- [ ] A daily note is created from the template with one command
- [ ] My work and due tasks render inside the note

## Checklist

- [ ] Open today's note from the calendar or with the Daily notes command
- [ ] Tick a task and watch the linked work item update
- [ ] Add one line to the Log at the end of the day
- [ ] Pin the Home note so the vault opens on the dashboard

## Notes

The template lives in Templates/Daily.md — tweak it freely; the widgets are plain code blocks.
