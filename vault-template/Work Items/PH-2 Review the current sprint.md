## Description

Create the first sprint and sanity-check it: dates, goal and capacity, then confirm which items belong to it. Sprints are ordinary notes under Sprints/ — create one with "Project Hub: New sprint" and link items to it from the board, backlog or quick-create modal.

## Acceptance criteria

- [x] A sprint exists with the right start and end dates
- [ ] The goal describes what this sprint commits to
- [ ] Every item that belongs to the sprint is linked to it

## Checklist

- [x] Run "Project Hub: New sprint" and pick the dates
- [ ] Drag the onboarding items into the sprint from the Backlog
- [ ] Confirm the scope with the team
- [ ] Set the capacity so the backlog view can flag over-commitment

## Notes

The Home burndown follows the current sprint automatically. The capacity field feeds the capacity bar in the backlog view — leave it empty if you don't track capacity.
